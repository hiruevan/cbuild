cbuild - C Build Helper for Calculator and Desktop Platforms
Version: 1.8.12

Usage:
  cbuild --version
  cbuild -help
  cbuild install [-cal] [-win] [-lnx [architecture ...]] [-all] [-force]
  cbuild uninstall [-all] [-force]
  cbuild make  (-cal | -win | -webp | -lnx [architecture ...] | -all)
  cbuild clean (-cal | -win | -webp | -lnx [architecture ...] | -all)
  cbuild export (-cal | -win | -webp | -lnx [architecture ...] | -all)

Supported targets:
  -cal        TI-84 Plus CE calculator (CEdev + GNU Make).
  -win        Windows desktop (MSYS2 UCRT64 + GCC + CMake + Ninja + SDL2).
  -webp       Browser build: one stand-alone HTML file (Emscripten via WSL2 + SDL2).
  -lnx        Linux desktop through WSL2 (x86_64 by default).
  -lnx aarch64
              Linux ARM64 cross-compilation.
  -lnx armhf  Linux ARM hard-float cross-compilation.

macOS:
  macOS is not currently a supported cbuild target.
  The CMake template has an initial Apple bundle branch, but cbuild does
  not yet install, build, clean, or export macOS targets.

Commands:
  install     Installs cbuild and selected target dependencies.
  uninstall   Removes cbuild and selected installed dependencies.
  make        Builds selected targets. Run from a project directory
              containing Project.mk.
  clean       Removes generated build and binary output directories.
  export      Copies recognized build outputs into the EXPORT directory.

Install flags:
  -cal        Installs the TI-84 Plus CE calculator toolchain.
  -win        Installs Windows desktop build dependencies.
  -webp       Installs the Webpage desktop build dependencies.
  -lnx        Installs WSL2/Linux dependencies (x86_64 by default).
  -all        Installs dependencies selected by PLATFORMS in Project.mk.
  -force      Forces the base cbuild installation to be recreated.

Note: cbuild install -all reads Project.mk from the current directory.
Run it from a project root. Use cbuild install (without -all) for only
the base cbuild installation.

Make flags:
  -cal        Builds the calculator target.
  -win        Builds the Windows desktop target.
  -webp       Builds the Webpage desktop target.
  -lnx        Builds the selected Linux architecture (x86_64 by default).
  -all        Builds targets selected by PLATFORMS in Project.mk.

Clean flags:
  -cal        Removes the calculator build and binary directories.
  -win        Removes the Windows build and binary directories.
  -webp       Removes the Webpage build and output directories.
  -lnx        Removes the selected Linux build and binary directories.
  -all        Deletes the complete BUILD and BIN directories from Project.mk.

Export flags:
  -cal        Exports calculator output files.
  -win        Exports Windows output files.
  -webp       Exports Webpage output files.
  -lnx        Exports selected Linux output files.
  -all        Exports recognized files from all of BIN.

Export currently recognizes these file extensions:
  .8xp, .8xv, .exe, .elf, .html
  macOS .app bundles are not currently supported by export.

Linux architecture arguments (must follow -lnx):
  x86_64      Standard 64-bit Intel/AMD Linux (default).
  aarch64     64-bit ARM Linux cross-compilation.
  armhf       32-bit ARM hard-float Linux cross-compilation.

Examples:
  cbuild install
  cbuild install -cal
  cbuild install -win
  cbuild install -lnx
  cbuild install -lnx aarch64
  cbuild install -lnx armhf
  cbuild install -all

  cbuild make -cal
  cbuild make -win
  cbuild make -lnx
  cbuild make -lnx aarch64
  cbuild make -lnx armhf
  cbuild make -lnx aarch64 armhf
  cbuild make -all

  cbuild clean -cal
  cbuild clean -win
  cbuild clean -lnx
  cbuild clean -lnx aarch64
  cbuild clean -lnx armhf
  cbuild clean -all

  cbuild export -cal
  cbuild export -win
  cbuild export -lnx
  cbuild export -all

Project configuration:
  make, clean, and export read Project.mk from the current directory.
  NAME is required. Other settings are optional:

    NAME        Project name (required)
    DESCRIPTION Project description (defaults to NAME)
    TARGET      Output target name (defaults to NAME)
    BIN         Binary output directory (defaults to bin)
    BUILD       Build/intermediate directory (defaults to build)
    EXPORT      Export destination (defaults to export)
    SRCDIR      C source directory (defaults to src)
    INCLUDE     Header directory (defaults to include)
    RESOURCES   Resource directory (defaults to resources)
    ICON        The name of the icon file (inside resources directory, .ico extension)
    SRC         Entry-point source file (defaults to main.c)
    PLATFORMS   Targets used by -all (defaults to cal win lnx)

Valid PLATFORMS values:
  cal, win, webp, lnx, lnx-x86_64, lnx-aarch64, lnx-armhf

Notes:
  - Run cbuild commands in Windows PowerShell.
  - Linux builds run through WSL2.
  - make, clean, and export must be run from the project root.
  - install -all also reads Project.mk and must be run from a project root.
  - clean -all deletes the entire configured BUILD and BIN directories.
    Do not keep unrelated files in those directories.
  - If a build fails due to stale generated files, clean the affected target
    and rebuild it.
